# Employee Attrition Prediction Using Machine Learning – Salifort Motors

## 📌 Business Problem
Employee attrition significantly impacts organizational productivity and cost.  
The objective of this project is to build a predictive model to identify employees at risk of leaving, enabling HR teams to take proactive retention measures.

---

## 📊 Dataset

- **14,999 employee records**
- 10+ HR-related features including:
  - Satisfaction level  
  - Tenure  
  - Workload  
  - Performance evaluation  
  - Overtime  
  - Salary level  

The dataset contains structured workforce data suitable for classification modeling.

---

## 🛠 Tools & Technologies

- Python  
- Pandas  
- NumPy  
- Seaborn  
- Scikit-learn  
- Logistic Regression  
- Random Forest  

---

## 🔍 Approach

1. Performed data cleaning and validation.
2. Conducted exploratory data analysis (EDA) to identify attrition patterns.
3. Engineered relevant features influencing employee behavior.
4. Built classification models:
   - Logistic Regression  
   - Random Forest  
5. Evaluated model performance using Accuracy, Precision, Recall, and F1 Score.

---

## 🤖 Model Performance

### ✅ Best Performing Model: Random Forest

- **Accuracy:** 84.87%
- **Precision:** 83.41%
- **Recall:** 86.92%
- **F1 Score:** 85.13%

The model achieved strong recall performance, improving detection of employees likely to leave.

---

## 📈 Key Business Insights

- Employees with **low satisfaction levels** are significantly more likely to leave.
- High overtime correlates strongly with increased attrition risk.
- Longer tenure combined with low performance rating increases churn probability.
- Predictive modeling enables proactive HR intervention strategies.

---

## 🎯 Business Impact

This model enables HR teams to:

- Identify high-risk employees early  
- Improve workforce planning  
- Reduce turnover costs  
- Implement data-driven retention strategies  

---

## 📎 Project Outcome

An end-to-end machine learning pipeline was successfully developed for employee attrition prediction, demonstrating practical application of predictive analytics in HR decision-making.
